# DiPlay TS7 v21.4

- 日期：2026-10-26（Asia/Taipei）
- 版本：`0.2.21-ts7-wudi81-v21.4`，versionCode `53`
- 套件：`com.shihab.diplay.ts7`，最低 Android API `24`

本版針對 TS7 精簡介面與不需要的背景工作，並在診斷報告加入觸控延遲分段數據。所有改動以 TS7 車機判斷為條件，其他車機維持原有行為。**本版尚未在 TS7 實車驗證。**

## 改了什麼

- CarPlay 的「回到車機」預設顯示 Toyota 名稱與 Toyota 圖示。使用者自訂的名稱或圖示仍優先。
- TS7 的主題設定仍由 Android 設定回呼即時更新；每 2 秒的安全輪詢改為每 60 秒一次。
- 無線連線成功後，停止本次連線用途已結束的無線啟動診斷取樣。
- 停止 TS7 不需要的 BYD HUD／儀表輸出與週期讀取、相關歌曲與車身狀態發布，以及氛圍燈分析和封面取色工作。浮動地圖卡片、側邊面板及桌面導航所需的路線資料仍保留。
- Host 與 session 診斷日誌改由單一背景 writer 排隊寫入；報告匯出前會先等待排隊資料寫完。
- 播放頭長時間不前進時，舊音軌會在時限內退出；其他音訊緩衝、延遲與補償參數沿用原設定。
- TS7 觸控事件不再逐次格式化並寫入邊緣事件日誌，也不再為每個 HID 觸控封包建立十六進位 trace；HID 寫入及封包順序保留。
- 診斷報告每 5 秒彙整四段延遲的 p50、p90、最大值與樣本數：
  - `touchEvent2Hid`：Activity 收到觸控到 HID 寫出。
  - `hid2FrameReceived`：HID 寫出到下一張影像幀完整收到。
  - `frameReceived2DecodeOutput`：影像幀收到到解碼輸出。
  - `decodeOutput2SurfaceSubmit`：解碼輸出到送交 Surface。

## TS7 設定頁

- 隱藏有線 USB 連線與充電、BYD 專用設定、DiLink 設定精靈，以及 TS7 不支援或可能造成不穩定的實驗性影音／音訊調校。TS7 上已儲存的舊值不會啟動這些工作；其他車機不受影響。
- CarPlay 手勢選單保留無線連線與熱點狀態、Toyota 標籤與圖示、解析度、影格率、安全區域、全螢幕、系統列、側邊面板、診斷、語言、設定、退出及儲存並重新連線。
- 保留浮動地圖卡片、側邊面板、桌面懸浮球、桌面導航小工具、手機備份與報告下載頁，以及儲存診斷報告和分享功能。
- 解析度預設維持 100%，可自行調整。影格率預設及音訊參數沒有變更。
- TS7 的影像／解碼值沿用 v21.3 實車設定：平滑影像關閉、直接輸出開啟、低延遲 H.264 SPS 開啟、影格結束標記附加、MTK 調校關閉。實際效果仍待實車確認。

## 安裝與實車檢查

- 已安裝 v21.3（versionCode 52）的 TS7 可直接升級至本版（53），保留設定。若仍裝著舊 DiPlay TS7 v0.2.48（versionCode 68），須先移除；Android 不允許以較低 versionCode 覆蓋。
- 使用平常的無線連線、解析度與影格率，確認 CarPlay 顯示、觸控、音訊，以及浮動地圖、側邊面板和桌面工具仍可使用。
- 匯出新的診斷報告，查看 `touchEvent2Hid`、`hid2FrameReceived`、`frameReceived2DecodeOutput`、`decodeOutput2SurfaceSubmit` 四段的 p50/p90/max/n。這些數據用來定位延遲所在階段，不代表任何延遲已改善。
- 確認日夜模式自動切換，且成功連線後無線啟動診斷停止週期取樣。
