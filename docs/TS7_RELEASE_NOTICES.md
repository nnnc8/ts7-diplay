# TS7 Full-Fork Baseline R1 notices

The upstream `LICENSE`, `docs/THIRD_PARTY_NOTICES.md`, attribution, dependency
licenses and upstream sources are preserved unchanged. Historical upstream
preview descriptions are not descriptions of this TS7 package.

This public TS7 baseline contains **no accessory authentication identity**.
Firmware-derived experimental identities are not approved inputs. Build-time
credential asset inputs are rejected, and the final APK is independently scanned.
Only explicitly legally authorized external provisioning may use the preserved
authentication interfaces. Technical parsing or a configured provider does not
establish authorization, certification or a working iPhone session.

The Apple icon is replaced in the TS7 build by an original neutral vector; the
original file remains in the upstream Git history. BYD donor maneuver PNGs are
excluded from the TS7 APK, with their notices and sources preserved in the Fork.
Their historical provenance has not been independently established. No claim
that those assets are freely relicensable is made.

TS7-specific source changes retain GPL/AGPL attribution. The complete receiver
source, upstream history, original licenses and separate TS7 changes are available
at https://github.com/nnnc8/ts7-diplay . Source archive packaging must retain the
build inputs and all applicable notices; any excluded non-packaged historical
image assets must be explicitly listed, never silently relabeled as TS7 assets.

This is an engineering baseline using a debug/test APK signature. It is not an
Apple-certified product and has not yet proved functional CarPlay on a real TS7
or iPhone. Original UI/media/controller implementations remain; vendor/lab
features are disabled by policy rather than source deletion.
